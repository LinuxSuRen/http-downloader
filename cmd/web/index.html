Launch command

Passed to the tool binary whenever it starts from here, e.g. server --port 8080. A leading tool name is ignored, quoted values keep their spaces. Leave it empty to start the tool plain.

 Install settings

These defaults are shared with the hd CLI and saved in ~/.config/hd.yaml.

 Submit your tool

Make your tool installable for every hd user: add a YAML config to the hd-home registry and open a pull request. The file lives at config/$org/$repo.yml in the hd-home repository, its contribution guide explains all fields.

filename: "{{.Name}}-{{.OS}}-{{.Arch}}"
binary: your-tool
targetBinary: your-tool
tar: true
formatOverrides:
  windows: zip
  linux: tar.gz
categories:
- ci
